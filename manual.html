📱 수업일지 사용설명서

종이 일지 대신 씁니다. 처음 설치 5분, 그다음부터는 수업하면서 숫자만 적으면 됩니다.

1처음 설치 — 딱 한 번, 5분

1
단체방에서 앱 링크 열기
링크를 누르면 카톡 안에서 열립니다. 여기서 바로 쓰면 안 돼요! ⬇
2
「다른 브라우저로 열기」
카톡 화면 오른쪽 아래 메뉴(⋮ 또는 공유 버튼) → 다른 브라우저로 열기 → 크롬(아이폰은 사파리)으로 엽니다. 카톡 안에 저장된 기록은 날아갈 수 있어서 꼭 필요합니다.
3
홈 화면에 추가
크롬: 오른쪽 위 ⋮ → 「홈 화면에 추가」
사파리: 아래 공유 버튼 → 「홈 화면에 추가」
→ 폰 바탕화면에 앱 아이콘이 생깁니다. 앞으로는 이 아이콘으로만 여세요.
4
가입하기
앱을 열면 로그인 화면이 나옵니다. 이메일·비밀번호(6자 이상)를 넣고 「처음입니다 — 가입하기」를 누르면 즉시 시작됩니다. 비밀번호는 꼭 메모해 두세요.
5
예시 회원 삭제
설정 탭 → 「예시 회원(김민수) 삭제」. 연습용으로 먼저 눌러보고 지워도 됩니다.
✓ 기록은 계정에 저장됩니다 — 같은 이메일로 로그인하면 폰이든 PC든 노트북이든 어디서나 같은 기록이 보입니다. 수업 중 적은 건 몇 초 안에 자동으로 서버에 저장되고, 인터넷이 잠깐 끊겨도 연결되면 알아서 올라갑니다.
⚠ 주의 둘 — ① 비밀번호를 잊으면 기록에 접근을 못 하니 꼭 메모하세요. ② PC에서 쓸 땐 같은 주소를 열고 같은 계정으로 로그인하면 됩니다.

2화면은 다섯 개뿐

👥회원오늘 수업·회원 목록
🗓시간표달력에 수업 예약
📋프로그램30회 운동 틀
🏋️운동운동 사전
⚙️설정백업·복원

3내 회원 넣기

1
회원 탭 → ＋ 회원 등록
이름 · 성별 · 주의사항(나이, 부상 이력) 입력. 등록하면 목록으로 돌아오니 연달아 등록하면 됩니다.
2
프로그램 배정
기본 「근력 A(30회)」가 들어 있습니다. 나만의 프로그램은 프로그램 탭 → 새로 만들기 — 루틴 2~4개 만들면 30회에 자동 배치됩니다.
3
시간표 탭에서 수업 예약
달력에서 날짜 탭 → 시간 옆 ＋ → 회원 선택. 홈 화면 맨 위에 「오늘 수업」이 시간순으로 뜹니다.

4수업하기 — 매일 하는 것

회원 누르기 → A-5 수업 시작 버튼 하나면 그날 운동 목록이 뜹니다.

1
운동 이름을 누르면 펼쳐진다
펼치면 위에 지난 기록(최대 무게·최다 반복·e1RM·특이사항)이 먼저 보입니다. 접힌 상태에서도 오른쪽에 「지난 30kg×8」이 작게 떠서 목록만 보고도 수업이 됩니다.
2
오늘 기록 입력 — 10초 룰
↺ 지난 기록 불러오기를 누르면 지난 세트가 그대로 깔립니다. 숫자만 고치세요. 맨몸 운동은 무게에 0, 플랭크 같은 건 초, 스트레칭은 완료 체크만.
3
특이사항은 색깔 버튼으로
허리 통증 빨강 = 아픈 것 · 통증 줄어듦 파랑 = 좋아진 것 · 왼쪽 약함 초록 = 좌우 불균형. 자세한 건 메모칸에.
4
회원에게 필요한 운동은 그 자리에서 추가
＋ 퍼스널 운동 추가 — 추가하면 다음 바퀴 같은 회차에도 계속 나옵니다. 필요 없어지면 「이 회차에서 빼기」.
5
수업 완료 → 카톡 전송
수업 완료 누르면 요약 카드가 만들어지고, 💬 카톡으로 보내기로 회원에게 전송. "지난번 대비 +8%"가 회원 폰에 남습니다.
✓ 입력이 날아갈 걱정 없음 — 수업 중 입력은 실시간 자동 저장됩니다. 실수로 다른 탭을 눌러도 홈의 「▶ 진행 중 수업」으로 이어집니다.

5알아두면 좋은 기능

🔍
운동으로 기록 찾기
회원 화면에서 "스쿼트" 검색 → 그 회원의 전체 이력과 통증 타임라인이 한 화면에.
📈
변화 리포트 — 재등록 상담 필살기
근력 상승 TOP3, 시간 기록 성장, 좋아진 것, 잡은 통증까지 한 장으로. 잔여 3회쯤 남았을 때 회원에게 보여주고 카톡으로 보내세요.
🗂
지난 기록 수정
숫자를 잘못 적었으면 회원 화면 → 지난 수업 기록 → 그 수업 눌러서 고치기. 잘못 저장한 수업은 통째 삭제도 됩니다.
🔁
재등록 처리
회원이 재등록하면 회원 화면 → 「재등록 처리」 → ＋1. 이름 옆에 재등록 2 배지로 쌓입니다. 잔여 3회부터는 재등록 타이밍 배지가 미리 뜹니다.
📋
프로그램 변경
30회 마치고 새 목표로 갈 때 회원 화면 → 프로그램 변경. 기존 기록은 운동별 이력에 전부 남습니다.
🚫
노쇼·취소 표시
시간표에서 예약을 탭 → 완료/노쇼/취소 선택. 수업 완료를 누르면 그날 예약은 자동으로 ✓ 처리됩니다. 노쇼가 쌓이는 회원이 눈에 보여요.
📋
주간 브리핑
매주 월요일 홈 맨 위에 자동으로 뜹니다 — 지난주 수업 수, 노쇼, 재등록 타이밍, 2주 넘게 안 온 회원까지. 이걸 보고 한 주를 시작하세요.

6저장 — 이제 자동입니다

1
따로 저장 버튼이 없습니다
숫자 하나, 칩 하나 누를 때마다 몇 초 안에 서버로 자동 저장됩니다. 홈 화면 위쪽 「✓ 서버에 저장됨」 표시로 확인할 수 있어요.
2
폰을 바꾸면?
새 폰에서 앱 열고 같은 계정으로 로그인 — 끝. 기록이 그대로 있습니다.
3
설정의 「백업 복사」는 보조 수단
서버가 다 저장하지만, 불안하면 가끔 복사해서 카톡 나에게 보내기 해두면 이중 안전장치가 됩니다.

7문제가 생겼어요

기록이 전부 사라졌어요!
십중팔구 다른 계정(이메일)으로 로그인한 겁니다. 설정 탭에서 로그인된 이메일을 확인하고, 원래 계정으로 다시 로그인하세요.
비밀번호를 잊었어요.
대표님께 말씀하세요 — 관리자 쪽에서 재설정을 도와드립니다. 그래서 처음에 메모가 중요합니다.
PC에서도 쓸 수 있나요?
네. PC 브라우저에서 같은 주소를 열고 같은 계정으로 로그인하면 폰과 똑같은 기록이 보입니다. 폰에서 적은 게 PC에 바로 뜹니다.
숫자를 잘못 저장했어요.
회원 화면 → 지난 수업 기록 → 그 수업 눌러서 수정.
수업 도중에 앱이 꺼졌어요.
다시 열면 홈 맨 위 「▶ 진행 중 수업」에서 그대로 이어집니다.
폰을 바꿔요.
옛 폰에서 백업 복사 → 새 폰에 앱 설치 → 설정에서 복원. 옛 폰이 없으면 카톡 나에게 보내기에 있는 마지막 백업으로.
쓰고 싶은 운동이 목록에 없어요.
운동 탭 → 내 운동 추가. 현장에서 쓰는 이름·약어 그대로 넣으면 됩니다. 기록 방식(무게/시간/레벨/밴드/체크)도 거기서 정합니다.
불편한 점·추가 요청은 대표님께 — 모아서 바로바로 업데이트됩니다.
업데이트는 자동 반영: 새로고침만 하면 최신 버전입니다.
